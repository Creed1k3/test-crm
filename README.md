# Объекты и задачи

Тестовая CRM для строительной компании. Постановщики управляют объектами и задачами, исполнители работают с назначенными им задачами и отправляют их на проверку.

Планируемый стек — React, TypeScript и Supabase. Политики доступа и правила смены статусов будут храниться в SQL-миграциях в `supabase/migrations/`.
